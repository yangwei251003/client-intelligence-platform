# 客户资讯台交接

以下是待填写模板，填写实际证据后才是交付报告。

## 打开与每日使用

- 客户/交付日期：
- 客户电脑系统、运行时、时区：
- 启动入口（绝对路径）、本地网址、关闭方法：
- 每天阅读范围、条数/分钟预算：
- 最近一次真实更新的时间、Run ID、结果及覆盖缺口：
- 分别记录：来源连通状态 / 模型或纯原始模式状态 / 客户要求的调度模式与当前状态：

## 首次配置（逐项截图或清晰步骤）

1. 网站首次设置入口；填写关注领域后推荐哪些来源、覆盖哪些地域/对象：
2. 网站模型连接页、预填供应商/模型、官方授权或 Key 获取入口、费用条件；客户需完成的唯一必要授权步骤：
3. 哪些来源自动连接且无需 Key；需要授权的来源在网站里如何连接；高级私有配置仅供维护者：
4. 网站自检与首次试运行方式；未配置、部分覆盖和成功如何区分：
5. 401/403、429、断网、预算耗尽、无结果分别怎么办：

## 每日自动更新

- 网站时间/时区、暂停/恢复入口；下次计划时间：
- 后台服务实际状态、心跳、自动启动方式和运行身份；高级维护才列任务/命令：
- 关机/睡眠/未登录时的行为与补跑条件：
- 最近一次调度器触发证据、退出码、对应 Run ID：
- 浏览器关闭期间的自动更新证据、重启补跑结果、页面自动呈现新日报证据：
- 每日概览/事件摘要、最新/热门排序依据、“阅读原文”实测结果：
